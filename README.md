2진법->10진법 전환
1. 각 자리의 숫자를 공식[변환하고자하는 수 x 2^(자리수-1)]을 이용하여 결과값을 구한다
2. 결과값을 모두 더하면 10진수가 된다
ex)1011
첫번째 자리: 1 x 2^0=1 
두번째 자리: 1 x 2^1=2 
세번째 자리: 0 x 2^2=0
네번째 자리: 1 x 2^3=8 
1+2+0+8=11
1011(2진수) = 11(10진수)

10진법 -> 2진법 전환
1. 10진수를 2로 나누고, 해당 나머지를 기록한다
2. 나눈 몫을 또 다시 2로 나누고, 해당 나머지를 기록한다
3. 이렇게 계속해서 나눈 몫을 2로 나누다가 나눈 몫이 2보다 작아지면 중단한다
4. 마지막 몫과 지금까지 기록한 나머지들을 역으로 연결하면 2진수가 된다
ex)55를 2로 나누면 몫=27 나머지=1
     27을 2로 나누면 몫=13 나머지=1
     13을 2로 나누면 몫=6 나머지=1
     6을 2로 나누면 몫=3 나머지=0
     3을 2로 나누면 몫=1 나머지=1
55(10진수) = 110111(2진수)

2진법 -> 16진법 전환
*16진법은 0에서 9까지의 숫자와 A에서 F까지의 알파벳을 사용하여 숫자를 표현한다 A=10 B=11 C=12•••F=15를 나타낸다
1. 2진수를 4비트(4개의 2진수자리)로 묶는다
2. 각각의 값을 10진수로 나타낸다
3. 10진수로 나타낸 값을 나타내는 16진수로 변환한 후 붙인다
ex) 110110111001
‘1101’= 13 ,1011’,=11 ‘1001’=9
13=D ,11=B , 9     ->DB9
110110111001(2진수)= DB9(16진수)

16진법 - > 2진법 전환
1. 각 16진수 자리를 4비트의 2진수로 변환한다
2. 변환된 2진수를 이어 붙인다
ex) 7A3
      7=0111
      A(10)=1010
      3=0011    ->011110100011
7A3(16진수)=011110100011(2진수)
